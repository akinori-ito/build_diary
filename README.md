# 日記HTML生成プログラム

`yyyymmdd.txt` 形式の日記と `photo` フォルダの写真から、公開用の静的HTMLを生成します。
Python 3.11以降が必要です。

## 準備

PowerShellでこのフォルダへ移動し、Pillowをインストールします。

```powershell
python -m pip install -r requirements.txt
```

## 実行

```powershell
python build_diary.py
```

初回実行時に `diary.toml` が作成され、生成結果は `public` フォルダへ入ります。
`diary.toml` のタイトル、全体概要、日付ごとの説明にはプレースホルダが入るので、公開前に編集してください。

編集後にもう一度同じコマンドを実行するとHTMLが更新されます。縮小画像は元画像より古い場合だけ再生成されます。

すべての生成物を作り直す場合は次を実行します。

```powershell
python build_diary.py --clean
```

## 入力形式

- ファイル名は `yyyymmdd.txt` とします。
- 先頭の空行を除いた最初の行が、ページの見出しとタイトルになります。
- それ以降の空でない通常行が本文になります。
- `#` で始まる行は写真指定です。複数のシンボルは空白で区切ります。

例：

```text
2026/11/4

朝食後に出発した。
#0041 0042
```

写真シンボルは、拡張子を除いた画像ファイル名の末尾と、大文字・小文字を区別せず照合します。
たとえば `0041` は `DSCF0041.JPG` に一致します。接頭辞、拡張子、シンボルの桁数は固定されません。

一致する写真がない場合や複数の写真に一致する場合は、誤った写真を公開しないよう生成を中止してエラーを表示します。参照されていない写真は無視します。

## 出力

```text
public/
├─ index.html
├─ yyyymmdd.html
├─ style.css
└─ miniphoto/
```

各日記ページには、実際に存在する日記を日付順に並べた「前の日へ」「次の日へ」と、「目次へ」のリンクが付きます。先頭・末尾に存在しない方向のリンクは表示しません。

`index.html` には全体概要、各日記へのリンクと説明、設定した上位一覧ページへのリンクが入ります。
